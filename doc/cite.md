# How to cite sourmash

The primary citation for the sourmash software is:

Irber et al., (2024). sourmash v4: A multitool to quickly search,
compare, and analyze genomic and metagenomic data sets. Journal of
Open Source Software, 9(98), 6830, [https://doi.org/10.21105/joss.06830](Irber et al., (2024). sourmash v4: A multitool to quickly search, compare, and analyze genomic and metagenomic data sets. Journal of Open Source Software, 9(98), 6830, https://doi.org/10.21105/joss.06830).
